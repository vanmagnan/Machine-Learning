Projects selected from the other folders, including:

SVD, PCA, LDA, Spectral Clustering, Multidimensional Scaling, SVMs, eigenfaces, document clustering, background removal via sparse SVD — all implemented from scratch using NumPy/SciPy.

## M 540: Numerical Methods

Numerical linear algebra — LU/QR factorization, sparse matrix algorithms, eigenvalue methods, floating-point computation.

## M 561 Big Data Analytics

Full scikit-learn ML pipeline work — classification, regression, random forests, gradient boosting, hyperparameter tuning, feature engineering, handling imbalanced data, and a complete NLP stack (NLTK, TF-IDF, Naive Bayes, topic classification, spam detection).

## M 562 Big Data Theory

From-scratch implementation of classical supervised and unsupervised ML algorithm, neural networks (including backprop, ReLU, ADAM optimizer), CNNs, recommender systems,  applied ML projects on MNIST, leukemia gene expression, and spam detection.
